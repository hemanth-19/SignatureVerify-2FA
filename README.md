# SignatureVerify-2FA
**SignatureVerify-2FA** is a secure signature verification system that combines deep learning and two-factor authentication to detect handwritten forgery. It uses MobileNetV2 for efficient feature extraction and calculates L1 distance between uploaded and registered signatures to assess similarity. If the similarity score exceeds a threshold, an OTP is sent via Twilio’s Verify API to complete the verification process. Built with TensorFlow, Streamlit, and Twilio, this project provides an interactive user interface for real-time verification and aims to enhance identity security in sensitive applications like banking and legal systems.
